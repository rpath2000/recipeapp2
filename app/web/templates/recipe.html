Form States (Design Documentation)

New Recipe Entry: Form displays with empty fields, no Recipe ID shown, character counts at 0.

Edit Existing Recipe: Recipe ID displayed as read-only text above form, name and ingredients fields pre-populated with existing data (line breaks preserved), character counts reflect current values.

Validation Error: Form redisplays with entered values retained, error messages shown beside relevant fields with role="alert", error fields highlighted with red border, character counts show current state.

Success State: Green confirmation message displayed at top of form with role="status" and aria-live="polite" for screen reader announcement, form can be cleared or remain populated for further edits.

Character Count Feedback: Count updates as user types (implementation note: would require JavaScript in actual app, shown statically here). Warning styling when approaching limit (>90%), error styling when at limit.
